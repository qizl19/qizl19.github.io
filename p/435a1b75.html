CAD/CAE 生态周报｜2026-10-26

发表于2026-10-26|更新于2026-10-26|CAD/CAE 生态周报
|字数总计:8.7k|阅读时长:21分钟|阅读量:

定位：面向 FreeCAD 动力学自动化工作流。

检索窗口：2026-10-19 08:43 至 2026-10-26 08:43（Asia/Shanghai）。本期只把窗口内可核验的官方预发布、合并提交、开发提交、论文原文与问题单列为动态；正式发布、开发中变更、预印本、产品声明、社区信号和“本周无重要变化”分级标注。

执行摘要

本周最值得投入的不是追逐新版本，而是把“装配引用—精确几何—多面体结果—材料接口”四段数据契约做成可复算门禁。FreeCAD 的开发分支已合并 SubShapeBinder 作为装配引用时选错原始面编号的修复，但该修复晚于 10 月 21 日 weekly，且 PR 明确指出旧关节需要重新打开确认，单纯 recompute 不够。OCCT 开发分支加强了 STEP 外部引用、装配结构与 AP242 PMI；VTK 开始以专门数组保存多面体面拓扑，并修正会改变涡核筛选的 Q/Delta/λci 计算。CalculiX 修正 Abaqus-compatible 非线性 UMAT 中有取向与几何非线性时的应力变换，不过没有随提交出现新的数值基准。AI/IGA 侧有量化亮点，但都应进入候选层：GraphCAD 在两组 EAGBench 上把图有效率做到 98.05%/96.58%，却仍把 NURBS 曲面重建留给后处理；神经材料超降阶把 9 小时训练降到 41 分钟；学习型多重网格的一次循环精度提高约 6 倍，却在 CPU 上没有实际速度优势；NURBS 壳拓扑优化用更少单元复现基准形态，但不处理修剪积分，且 Monte Carlo 与 Python Bézier 提取是瓶颈。

  • 把 SubShapeBinder 圆柱面装配引用加入保存—重开—重新确认—参数扰动回归，分别测试 RC2、weekly-2026.10.21 与含修复的开发构建。
  • 建立 OCCT STEP 外部引用/AP242 PMI 与 VTK 多面体面列表的双向真值集，比较装配层级、实例、修剪、面方向和数组哈希。
  • 只在隔离分支验证 AI/IGA：GraphCAD 输出先过 BRepCheck/STEP 重导入；ROM、学习求解器和 IGA 优化必须与 CalculiX/Gmsh 冻结基线比较误差、时间和失效域。

本周最优先的 3 项行动

  1. 封住 SubShapeBinder 引用漂移。用含圆柱 SubShapeBinder 的最小装配，记录源 Pad Face9、Binder Face1、关节轴线与残差；保存重开后主动重新确认关节，再改变上游特征使面号重排。通过判据是引用仍指向 Binder、轴线一致、无人工重选，且 FCStd 二次重开可复现。
  2. 把 STEP—VTK 多面体链做成可审计合同。准备含外部 STEP 引用、重复实例、AP242 PMI、NURBS 修剪面和 polygon/polyhedron 的小型真值集；比较 OCCT 旧/新开发版与 VTK 旧/新开发版的层级、单位、PMI 关联、控制点/权重/修剪环、面列表、cell type、体积和 SHA-256。
  3. 给 AI/IGA 建“收益必须覆盖验证成本”的门槛。GraphCAD 统计有效 B-Rep、STEP 重导入、闭合与拓扑稳定率；超降阶/学习求解器报告端到端墙钟、内存和域外误差；IGA 壳优化同时跑 Gmsh 二次壳—CalculiX 对照，未证明精度—成本优势前不接入生产参数闭环。

FreeCAD Assembly 自动化与 API/插件变化

weekly-2026.10.21 是官方开发测试构建，发布页明确“不用于生产”。本周最相关的修复是 10 月 24 日合并的 PR #33835：Assembly 的 isBodySubObject() 新增对 PartDesign::SubShapeBinder 的识别。对应 问题 #33811 在 RC2 与 1.1.4 中可复现：选择绑定后的圆柱面时，Assembly 取用了源特征的另一个轴；案例中 Pad 为 Face9，而 Binder 为 Face1。

状态边界很重要：这是已合并开发变更，不在 10 月 21 日 weekly 内，也不是稳定版保证。PR 还写明“关节需要打开并重新确认，recompute 不够”，且改动只有一行类型判定、未随提交新增自动测试。对自动化来说，风险不只是首次选面错误，还包括历史文档迁移、上游拓扑改变后引用是否继续落到 Binder、自顶向下重算能否触发正确的关节更新。建议把关节 XML/属性、轴线、位姿和求解残差都纳入保存重开差分。

本周其他 FreeCAD 开发提交主要涉及 GUI、TechDraw 和打包；没有新的 Assembly 公共 API 稳定性承诺。插件应固定 FreeCAD tag、Python/Qt/OCCT/VTK 组合，并把开发构建和 RC2 分开存档。

IGA / CAD–分析一体化

Robust topology optimization of isogeometric Kirchhoff–Love shells by the Speed Method 是窗口内合格的新 IGA 预印本。方法以多 patch、非匹配网格的 KL 壳为对象，用 NURBS level set 表示材料边界，以 speed method 得到体积分布式形状导数，再用双调和方程生成下降方向；实现基于 FEniCS、tIGAr 与 PENGoLINS，代码在 figaroIGA/figaro 开放。

证据量化结果开放性局限/失效模式FreeCAD 验证
四 patch 半球 KL 壳每 patch 40×40 三次 NURBS 单元，得到与文献 128×128×1 二次 solid IGA 相近的加强筋形态；目标约 30 次迭代后稳定，运行到 150 次论文、代码开放形态相近不等于几何误差/应力/条件数相同；未给端到端时间与内存同一 STEP/NURBS 壳跑 IGA 与 Gmsh 二次壳—CalculiX，比较位移、反力、模态、应变能、时间
单 patch 双抛物面40² 三次 NURBS，对比文献 64²；无需边界额外积分点公开实现可复跑当前方法主动避免 trimming；不能证明切割单元稳健性另建含内孔/短边/缝边的修剪壳，单独统计闭合误差、切割失败率与积分敏感性
随机载荷/材料Monte Carlo + Gaussian random field算法与代码开放每次迭代成本随样本数线性增长；Python Bézier extraction 是主要开销记录样本数—方差—墙钟 Pareto，并验证并行扩展

框架检索边界：固定窗口内检查 G+Smo、GeoPDEs、PetIGA、tIGAr 与 igatools，均未发现新提交或正式版本；IBRA、trimmed/immersed IGA、T-/THB-/LR-spline、接触、断裂、多物理、GPU/预条件的新量化工作也未达到纳入门槛。不得把既有框架能力写成这周新闻。

面向 FreeCAD/OCCT 的核心门禁仍是精确传递：从 Geom_BSplineSurface 提取次数、控制点、节点矢量、权重与参数域，从 TopoDS face 提取 3D 边、pcurve、内外环和方向；再比较 STEP 往返后的曲面 Hausdorff/法向误差、修剪闭合、C0/C1 跳量、边界积分、自由度、条件数、组装/求解时间和内存。本文的 NURBS level set 是分析/优化表示，不自动证明任意 OCCT 修剪 B-Rep 可保真导入。

AI × CAD/CAE

本期只纳入有 benchmark、量化结果且能形成 FreeCAD/CAE 验证实验的工作。所有结果在目标工作流复算前均为中等或偏低置信度。

工作/状态方法与数据量化结果开放性与局限工作流影响/验证
GraphCAD
MM 2026 论文/arXiv		边邻接图 EAG + 离散/连续混合扩散 + SE(3) 等变去噪；EAGBench-DC 95,392 个模型，另含 Fusion 360 子集无条件图有效率 DC 98.05%、FS 96.58%；条件生成 DC invalid ratio 1.67%、CD 1.73；K=100 时 5.06 GB、151 s/256 样本论文与 benchmark 描述开放，页面未声明代码；只原生表示线/圆弧/圆，样条分段圆弧化，NURBS 曲面靠后处理；大装配未验证可作 B-Rep 候选生成器；必须测 BRepCheck、闭合、非流形、STEP 重导入、参数扰动和装配约束残差
神经材料超降阶
预印本		POD + energy-conserving sampling/weighting + adjoint；polyconvex 神经能量；2 个实验集 + 1 个三维合成例两相试件训练 9 h→41 min；三维 48,672 自由度压到 6 模态，只采 116/15,625 单元，训练 13 min实验数据开放；本研究新生成数据承诺发表后公开，未见代码声明；canary full-order 周期与训练轨迹相关可迁移到材料参数标定/ROM；对未见载荷路径、网格、噪声和材料相做反力、位移场、切线与稳定性对照
学习型多重网格平滑器
预印本		非结构 P1 FEM、高对比椭圆问题；只学习固定多项式平滑器，保留 Galerkin 粗网格、deflation 与能量门禁一次 V-cycle 对导电通道能量误差优于 4-step Jacobi-PCG 5.7–6.1×；绝缘障碍 1.38–1.45×代码/检查点/记录开放；主例仅 3,486 未知量、二维、对比度 10⁴；CPU 端无速度优势，14-step 经典法更准适合评估而非替换求解器；以达到同一残差/能量误差的端到端时间、内存和域外载荷为判据
MLV-PINN 接触动力学
预印本		同时输出加速度、法向力和摩擦裕量；用运动方程、接触互补与 stick-slip 混合主变量约束；4 个离散/连续 benchmark摘要只称大步长下位移/速度误差显著降低，未给统一数值；含消融、长时积分和摩擦斜率测试论文开放，元数据未声明代码/数据；未证明三维复杂接触、能量长期稳定或与工业隐式求解器一致仅作为接触状态/初值建议；用非穿透、摩擦锥、能量、冲量、步长收敛和 CalculiX 接触结果盲测

范围覆盖结论：Text-to-CAD、programmatic CAD、CAD copilot、agentic CAD、约束求解与可验证装配本周没有比 GraphCAD 更可迁移且更开放的新证据；GraphCAD 本身是无/条件生成，不是语言 copilot，也不解决装配约束。几何理解/修复由其 EAG 与 B-Rep 重建相邻覆盖，但 NURBS/修剪保真仍不足。自动参数化与拓扑优化由本期 IGA 壳优化和 SNTO 提供候选信号，后者扩展到 800 万 collocation points/8 GPU，却缺少与 FreeCAD/CalculiX 的开放复算链。AI 辅助网格、边界条件/载荷识别、digital twin、后处理与异常检测没有达到同等门槛的新结果；参数标定、solver acceleration、ROM/surrogate 由超降阶与学习平滑器覆盖；PINN/接触由 MLV-PINN 覆盖；neural operator 有多篇窗口内预印本，但未发现比上述工作更直接的 FreeCAD 动力学迁移证据。共性风险是训练分布外几何、视觉/分布指标替代拓扑与物理正确性、峰值倍率选择性报告，以及开放代码/数据不完整。

CATIA 与 Rhino / STEP / 3DM 互操作

OCCT 开发提交 8f95c78c 是本周互操作主信号：为 STEP、glTF、OBJ、VRML 增加 named companion streams，解析 STEP 外部引用并保留装配结构，补充 AP242 tessellated draughting model complex entities，并修正 GD&T 单位、runout 引用与 presentation context。它包含广泛回归测试，但仍是开发提交，不是 OCCT 正式 release。

另一开发提交 53706f78 修正曲线—曲面求交、闭合多边形自交、Newton 回溯与拟合端点曲率，并在 profile normalization 中保留有理截面几何和均值为 1 的权重。对 IGA/STEP 链路，这是“更少破坏有理几何”的正向信号，但仍需直接比较控制点、节点矢量、权重和参数域。

rhino3dm 提交 2bfb1db7 只在 Python/C++ 绑定文档中明确 MeshVertexList.Add 会舍入到单精度；它不是双精度网格实现。CATIA 本周未发现可独立核验的 STEP/3DM 互操作正式发布，商业材料仅按产品声明处理。验证集应覆盖 CATIA→STEP→OCCT/FreeCAD 与 Rhino→3DM→rhino3dm：实例层级、单位、属性、PMI 关联、NURBS 控制点/权重、修剪环、体积/质心和网格坐标误差都要逐项差分。

Gmsh 与 meshio

本周无重要变化。对 Gmsh 官方 master 的提交历史核验显示，窗口内没有提交，最近提交停在 10 月 18 日；meshio 官方仓库在窗口内也没有提交或 release。此前的多面体与分区性能变更不在本周重复包装。

冻结已验证版本，并保留三组回归：高阶周期节点及 Jacobian；polygon/polyhedron 在 MSH/MED/legacy VTK 的面列表、方向、物理组和体积；稀疏编号分区网格的读写时间、峰值内存与内容哈希。OCCT 本周 STEP 变化与 VTK 本周多面体变化都可能让中间格式消费者暴露兼容缺口，meshio 未声明支持的字段不得假定无损。

VTK 与 ParaView

VTK 开发分支加入 vtkPolyhedronCellArray（提交净增约 1,166 行），随后让 vtkUnstructuredGrid 使用该结构。这为 cell connectivity 与 face stream 提供专门容器；迁移风险在于旧代码直接假定通用 vtkCellArray 布局。另一个 cell type 性能/缓存修复同时修正插入单元后 distinct type 缓存未失效的问题，说明“更快”与“结果正确”必须一起测。

涡核判据修复具有明确数值锚点：旧实现把速度梯度缩小一半，并误用谱范数代替 Frobenius 范数；拉伸线性涡测试中旧值为 Q=0.5、Delta=0.075、λci=1，正确闭式值为 3.25、5.79、2。这会改变哪些单元进入 core-line 提取，历史后处理结果应标记版本。

ParaView 开发分支修正 SaveStateAndScreenshot 在新视图上错误使用 400×400 默认尺寸，以及 多输出端口 source 的 point picking 只访问端口 0。自动报告应校验最终图片像素、活动 view/layout 与输出端口 ID，而不是只判断脚本退出码。

CalculiX 与 Abaqus-compatible 流程

CalculiX 作者仓库在 10 月 23 日连续合并两项 umat_abaqusnl_total.f 开发修正。b80d19d5 把有材料取向时的旋转施加到 corotational stress，再用 U^{-1} pull-back；71095374 区分线性几何与非线性几何，非线性时使用机械右伸长与对应 Jacobian 计算应力因子。

这是 Abaqus-compatible UMAT 语义的实质修正，但提交没有新增输入 deck 或参考输出，不能仅凭编译通过宣布兼容。应构造四象限材料点/单元测试：取向开/关 × 几何非线性开/关，再叠加热膨胀；比较刚体旋转客观性、应力 pull-back/push-forward、反力、切线有限差分、Newton 收敛和能量。使用 Abaqus 结果时注明它是外部参考，不把关键词兼容等同于数值等价。

Python / C++ / pybind11 / ABI

pybind11 本周没有正式 release，但开发分支修复了两类与 FreeCAD 插件前瞻兼容密切相关的问题。d7979427 为 local exception translator 注册加锁，附带 free-threaded 并发导入测试；bf6e3afa 避免 free-threaded Python 上每次 bound call 都获取 internals mutex，并用 watchdog 测试证明 dispatcher 不再依赖该锁。这些是 Python 无 GIL 路径的开发修复，不是 FreeCAD 当前 ABI 已切换的信号。

11ee91ee 让受检 NumPy array accessor 支持负索引，改变了边界语义。插件矩阵应覆盖目标 FreeCAD Python、MSVC/clang-cl、Release/Debug、pybind11 固定版本与 NumPy；测试并发导入、异常翻译注册、跨模块类型识别、析构、负索引与越界。任何二进制轮子升级均需重新跑 FCStd 保存重开与长时批处理。

来源与证据边界

本期联网核对 FreeCAD、Gmsh、meshio、VTK、ParaView、CalculiX、pybind11、rhino3dm、openNURBS、OCCT、G+Smo、GeoPDEs、PetIGA、tIGAr、igatools 的官方 release、提交或合并记录，并通过 arXiv 官方 API 与论文 HTML 原文筛选窗口内研究。FreeCAD weekly 是预发布；Assembly、OCCT、VTK、ParaView、CalculiX、pybind11 与 rhino3dm 条目均是开发状态；AI 与 IGA 条目为会议论文或预印本；CATIA 仅保留产品声明边界；Gmsh、meshio 与主流 IGA 框架明确记为本周无重要变化。论文/提交给出的倍率和指标尚未在本机 FreeCAD—Gmsh—CalculiX—VTK 流程复现，因此都配套验证实验，不写成生产收益保证。
