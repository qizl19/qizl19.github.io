CAD/CAE 生态周报｜2026-08-24

发表于2026-08-24|更新于2026-08-24|CAD/CAE 生态周报
|字数总计:4.9k|阅读时长:12分钟|阅读量:

检索窗口：2026-08-17 09:00—2026-08-24 09:00（Asia/Shanghai）。

证据口径：只把窗口内的正式发布、已合并变更、论文原文或可核验工程材料列为本周动态；预发布、开发中变更、预印本、产品声明和社区信号分别标注。

定位：面向 FreeCAD 动力学自动化工作流。

执行摘要

本周应把验证资源投向“高阶几何—网格—结果数据”的可复算链路。Gmsh 开发分支报告高阶网格生成约 3 倍加速、B-spline 高阶点投影约 100 倍加速；FreeCAD 修正非平行面中面的真角平分定位；VTK/ParaView 补强 CellGrid、CellArray 与 Fides 数据一致性。这些都是潜在高收益信号，但除 FreeCAD 周构建外均不是稳定发布，性能数字也必须在本机模型上复测。

  • FreeCAD：weekly-2026.08.20 是测试用预发布；Assembly 目录本窗口只有翻译更新，未核验到求解器或公共 API 的实质变化。
  • Gmsh：高阶生成与 B-spline 投影的开发提交给出约 3×、约 100×的作者侧测量，值得优先复算，但不能直接当作生产承诺。
  • 互操作/后处理：rhino3dm 增补 3DM 模板设置作者信息并修正 wasm64 内存上限；VTK/ParaView 的数据类型保留和错误检查降低静默损坏风险。
  • IGA 与 AI：固定窗口内未核验到满足原始来源、时间与量化门槛的重要新发布或论文；本期保留独立章节和验证边界，不用旧成果补新闻。

本周最优先的 3 项行动

  1. 复算 Gmsh 高阶性能。选择一个解析 B-spline 面、一个修剪 NURBS 壳和一个 STEP 复杂曲面，固定阶次、尺寸场与线程数；比较提交前后投影耗时、总网格耗时、节点坐标差、Jacobian 最小值和失败率。
  2. 给 FreeCAD 中面修复建立几何回归。用平行、微斜、强斜三组面构造 Part 中面，记录到两基准面的有符号角度/距离差，并把生成结果导入装配与网格流程。
  3. 升级 VTK/ParaView 数据门禁。在导入后检查 CellGrid 单元类型全集、CellArray legacy 偏移合法性、Fides 数组形状与时间步；任何缺失或形状变化都应终止流水线。

主题证据状态量化/变化工作流判断
FreeCAD 2026-08-20 周构建测试预发布commit 2bb00c9隔离验证，不替换生产版
Gmsh 高阶网格已合并开发提交约 3×、B-spline 投影约 100×（提交说明）高优先级复算

rhino3dm已合并开发提交3DM 模板设置接口；wasm64 内存上限修复中优先级往返测试

FreeCAD Assembly 自动化与 API/插件变化

weekly-2026.08.20 明确标为预发布，适合测试而非生产。本窗口对 src/Mod/Assembly 的官方提交记录核验到的只有翻译更新，未发现 Assembly 求解器、自动化 API 或插件接口的实质变更，因此不把相邻模块变化包装成 Assembly 新闻。

几何侧值得关注的是提交 2bb00c91：Part 中面在两非平行面之间改为真角平分定位。对基于中面建立装配基准、壳抽取或载荷方向的脚本，这会改变结果但提高几何语义一致性。FEM 提交 1f74ec9e 移除已弃用的 FreeCADGui.SendMsgToActiveView 调用，是兼容性清理而非新功能。

验证：建立非平行面夹角 0.1°、5°、30° 三档，比较中面法向与理论角平分线误差；随后保存/重开、STEP 往返、生成二次网格并检查节点到中面的偏差。

IGA / CAD–分析一体化

本周无重要变化。固定窗口内对 G+Smo、GeoPDEs、PetIGA、tIGAr 和 igatools 的官方/项目仓库检索，未核验到新的正式版本或已合并重要变化；因此不复述窗口外的 NURBS、THB-spline、LR-spline、trimmed/immersed IGA 成果。

本周仍应验证 FreeCAD/OCCT 到分析模型的精确几何传递：逐面导出次数、控制点、节点矢量、权重、参数域、周期性、外环/内环修剪曲线及 pcurve；重构后记录 Hausdorff 几何误差、边界闭合误差、跨面连续性和参数映射可逆性。对 trimmed/immersed IGA 记录切割单元比例、积分点数、条件数、预条件迭代数、自由度、组装/求解时间和峰值内存。

可复算对照：同一修剪 NURBS 薄壳分别走 IGA 与“Gmsh 二次网格—CalculiX”传统 FEM，统一材料、载荷和边界条件，比较静力位移、前六阶固有频率与总耗时；若修剪积分或边界施加不稳定，应将结论限制在研究验证层。

AI × CAD/CAE

本周无符合纳入门槛的重要新成果。本次检索覆盖 Text-to-CAD、programmatic/agentic CAD、装配约束、几何理解/修复、自动参数化、拓扑优化、AI 辅助网格、边界条件识别、参数标定、求解器加速、ROM、surrogate、PINN、neural operator、digital twin、后处理和异常检测；未找到同时满足窗口内、原始论文/官方仓库、可量化且对 FreeCAD 动力学可迁移的新增材料。

这不是“领域无进展”，而是证据门槛的结果。继续沿用四层门禁：L0 脚本可执行、B-Rep 有效、STEP 可重导入；L1 尺寸/拓扑/制造约束；L2 参数扰动和指定编辑；L3 固定 Gmsh/CalculiX 模板下的位移、应力分位数、柔度与模态成对复算。任何 CAD copilot 或代理若不能输出参数来源、约束状态、失败日志和可重放操作，就不进入自动发布/求解链。

CATIA 与 Rhino / STEP / 3DM 互操作

rhino3dm 合并提交 02cd3c6b，为 3DM 设置补充模板作者信息等绑定；提交 15df2003 修正 wasm64 最大内存限制。二者均是开发提交，不是新稳定发布，也不能外推为 CATIA/STEP 语义保真提升。

验证：构造含 NURBS 曲面、内孔修剪、图层、单位和模板作者元数据的 3DM；执行 Python—JavaScript/wasm64—3DM 往返，核对控制点/节点/权重、修剪环、对象属性、单位与文件哈希差异。本窗口未核验到 CATIA 或 STEP 官方规范/API 的重要发布。

Gmsh 与 meshio

Gmsh 开发提交 8357c0c7 报告在不改变网格的前提下将高阶网格生成加速约 3 倍；提交 9a260b8d 让高阶点投影利用初值，在 B-spline 上报告约 100 倍加速。相关提交还加入每线程 OCCFace 投影器与曲线单元并行处理。数字来自提交说明，尚未构成独立基准。

试件固定条件性能指标等价性指标
解析 B-spline 面阶次、尺寸场、线程数投影/总耗时，10 次中位数节点坐标最大差、连接哈希
修剪 NURBS 壳修剪环、曲率与目标尺寸投影失败率、峰值内存边界偏差、最小 Jacobian
复杂 STEP 曲面同一 OCCT 输入与物理组壁钟时间、线程扩展性单元数、物理组保留率

复现实验：固定 CPU 亲和性、线程数、阶次和网格尺寸，对三个几何各运行 10 次；同时比较节点坐标最大差、元素连接哈希、Jacobian 分布、投影失败率和峰值内存。meshio 官方仓库本窗口无提交，应维持版本冻结并用 MSH4 分区导出样例做往返测试。

VTK 与 ParaView

VTK 提交 293b1f0c 让 CellGrid I/O 保留全部单元类型；218e3053 增强 legacy CellArray 格式的错误检查；2f00d39c 暴露 WebGPU 数据回读到 CPU 的封装方法。这些都属于开发分支信号。

ParaView 在 485afa33 同步近期 Fides/CellGrid 修复，并合并了 CAVE 交互修复与插件安装目录传播调整。对自动后处理，优先测试多单元类型文件往返、缺损 legacy 数组的显式失败、Fides 时间序列数组形状，以及 GPU—CPU 回读内容一致性。

CalculiX 与 Abaqus-compatible 流程

本周无重要正式发布。自动化侧继续把“输入可解析”和“物理结果可信”分成两道门：先检查集合、单元、材料、载荷、接触和输出关键字是否被目标 CalculiX 版本接受，再用解析解或 Abaqus-compatible 基线比较位移、反力平衡、应力分位数和前六阶频率。Gmsh 高阶性能变更只影响前处理效率，不能替代求解结果等价性检查。

Python / C++ / pybind11 / ABI

pybind11 提交 22bf5b6e 修正 NumPy dtype 宏对 PYBIND11_TYPE 包裹类型的支持；a49c4dbf 让选项驱动的宏定义通过 pybind11_headers INTERFACE 目标传播。二者是已合并开发修复，不是稳定版升级指令。

门禁：在 MSVC 与 clang-cl 上各编译 Release/Debug，覆盖 NumPy dtype 注册、异常跨边界、FreeCAD 内嵌 Python 加载和卸载重载；审计最终编译命令中的宏定义与 CRT。编译通过不等于 ABI 安全。

决策与监控清单

事项本周决策通过判据主要风险
FreeCAD 周构建隔离测试中面几何、保存重开、STEP/网格回归全部通过预发布行为变化
Gmsh 高阶加速最高优先级复算性能提升可重复且网格/质量不退化模型依赖、线程波动
VTK/ParaView加入数据一致性门禁单元类型、数组形状、时间步与回读哈希一致静默丢类型或数组损坏
rhino3dm开发版只做往返实验NURBS、修剪、元数据与单位保真把局部接口变化误当全面互操作
IGA / AI维持实验基线几何、约束、求解均可复算后再升级旧成果冒充本周进展

来源与证据边界

  • FreeCAD weekly-2026.08.20、Part 中面修复、FEM 弃用 API 清理。
  • Gmsh 高阶生成、B-spline 投影；性能数字来自提交说明，需独立复测。
  • VTK CellGrid I/O、CellArray 校验、ParaView Fides/CellGrid 同步。
  • rhino3dm 模板设置接口、wasm64 内存修复。
  • pybind11 dtype 宏修复、INTERFACE 宏传播。

“已合并”仅表示进入开发分支，不等于稳定版本；周构建、提交说明与产品声明均不能替代目标环境中的回归、复算和验收。本期未用窗口外旧成果填充“本周新闻”。
